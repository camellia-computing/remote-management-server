# Security policy

## Supported versions

Only the latest released stable version is supported. This project is prelaunch;
development snapshots receive no security support.

## Reporting

Do not open a public issue. Use GitHub private vulnerability reporting for this
repository. Include the affected commit/version, impact, reproduction, and any
suggested mitigation. Do not include production credentials or personal data.

We aim to acknowledge a complete report within three business days, provide an
initial severity assessment within seven days, and coordinate disclosure after a
fix is available. These targets are operational goals, not a warranty.
